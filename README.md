# IT Step Academy — Software Development Programme (2024)

A collection of assignments and projects completed during the **Software Development** programme at [IT Step Academy](https://itstep.org/).

This coursework covers core programming fundamentals, object-oriented principles, version control workflows, and practical problem solving across multiple languages.
